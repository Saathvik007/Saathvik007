# Saathvik Maheshuni

Hi, I'm Saathvik. I do data and business analysis projects with SQL, Excel, Python and Tableau. Each project below has a repo with the code or model, the results, a one-page memo, and a Tableau dashboard.

| Project | What I found | Repo | Dashboard |
|---|---|---|---|
| E-commerce operations analysis | I looked at 96,470 delivered Olist orders. Late orders averaged 2.27 review stars compared with 4.29 for on-time orders, and 72.2% of late orders reached the carrier on time, so most of the delay happens during shipping. | [ecommerce-operations-analysis](https://github.com/Saathvik007/ecommerce-operations-analysis) | [Late deliveries and review scores](https://public.tableau.com/app/profile/saathvik.maheshuni/viz/E-commerceoperationsanalysislatedeliveriesOlist/LatedeliveriesandreviewscoresOlist2016-2018) |
| Premium-screen investment model | I built an Excel model from AMC and IMAX 10-K numbers. Converting a regular screen to a premium screen has a base-case NPV of -$213,905, and it only breaks even if attendance goes up 115.7%. | [premium-screen-investment-model](https://github.com/Saathvik007/premium-screen-investment-model) | [NPV per screen by scenario](https://public.tableau.com/app/profile/saathvik.maheshuni/viz/Premium-screeninvestmentmodel/Premium-screenconversionNPVperscreenbyscenario) |
| Event check-in system case | Requirements, process maps, a SQLite prototype and 18 acceptance tests for a made-up career office. In the synthetic data, 15.6% of the old spreadsheet rows needed a fix or a check, and 43.9% of registrations were no-shows. | [event-checkin-system-case](https://github.com/Saathvik007/event-checkin-system-case) | [Attendance and follow-ups](https://public.tableau.com/app/profile/saathvik.maheshuni/viz/Eventcheck-insystemcase/Eventcheck-inattendanceandfollow-upssynthetic) |

You can find more of my dashboards, including five earlier ones, on my [Tableau Public profile](https://public.tableau.com/app/profile/saathvik.maheshuni).
